## Context

目标仅为：新增一套基于 **Ubuntu 26.04** 的 OSM 瓦片地图 Docker 配置，功能与现有 Ubuntu 24.04 版本一致，可通过 Leaflet 网页浏览地图。不加入 Nominatim、OSRM，也不参考前述文章。

为减少重复并保证功能一致，不复制整套配置；将现有 Dockerfile 的 Ubuntu 版本参数化，默认仍为 24.04，再用独立 Compose override 构建和运行 26.04 版本。

## 实施方案

### 1. 参数化现有镜像的 Ubuntu 版本

修改：

- `docker/Dockerfile`
- `docker/Dockerfile.renderd`

在两处加入 `ARG UBUNTU_VERSION=24.04`，并将 `FROM ubuntu:24.04` 改为 `FROM ubuntu:${UBUNTU_VERSION}`。默认构建结果不变；26.04 构建沿用现有 CN APT 镜像、全部存储后端、renderd、Mapnik、osm2pgsql、openstreetmap-carto 和 Leaflet 资源。

若 Ubuntu 26.04 有个别软件包名变化，仅做必要兼容处理，不改变服务行为。

### 2. 新增 Ubuntu 26.04 Compose 配置

新增 `docker-compose.ubuntu26.yml`，通过 build args 为模块镜像和真实渲染镜像设置 `UBUNTU_VERSION=26.04`，并使用独立镜像标签：

- `ngx-mod-tile:ubuntu26.04`
- `ngx-mod-tile-renderd:ubuntu26.04`

提供独立端口，便于与 24.04 栈并存比较：

- demo 地图：8096
- 真实 OSM/Mapnik 地图：8097

启动时使用独立 Compose 项目名隔离容器和卷，不覆盖现有 24.04 数据。

### 3. 文档与使用入口

更新 `README.md`，给出明确命令：

```bash
# Ubuntu 26.04 demo 地图
docker compose -p ngx_mod_tile_u26 \
  -f docker-compose.yml -f docker-compose.ubuntu26.yml \
  up -d --build renderd tileserver

# Ubuntu 26.04 真实 OSM 地图
docker compose -p ngx_mod_tile_u26 \
  -f docker-compose.yml -f docker-compose.ubuntu26.yml \
  up -d --build db import osm-renderd osm-tileserver
```

说明地图地址、PBF 准备、镜像标签、与 24.04 并存方式及数据隔离。

## 验证

1. 构建模块与 renderd 镜像，并检查容器 `/etc/os-release` 确认为 Ubuntu 26.04。
2. 启动 demo 栈，验证 Leaflet 页面、已有瓦片、按需渲染、`/metrics` 均正常。
3. 使用现有轻量 Baku PBF 启动真实 OSM 栈，验证导入和真实瓦片渲染。
4. 分别对 8096、8097 执行现有 Playwright 测试，确认页面加载、缩放、拖动及瓦片请求与 24.04 一致。
5. 保持现有 C 模块源码不变；最后确认原 24.04 配置仍可默认构建。
